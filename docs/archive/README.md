# Archive - Documentos Históricos

## Localização
Histórico de versões antigas e documentação obsoleta.

## Estrutura
- `/v1_Proposals/` - Original project concepts, deprecated proposals
- `/Old_Versions/` - Previous SDDs, old diagrams, obsolete specs
- `/Deprecated/` - Cancelled initiatives, removed features

## Política de Limpeza
Mova para Archive:
- Documentos com mais de 6 meses sem atualização
- Propostas rejeitadas ou supersedidas
- Specs de features removidas

**Nunca delete - mantenha para histórico.**
